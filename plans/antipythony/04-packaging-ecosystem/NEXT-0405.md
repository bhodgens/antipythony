## GOTCHAS for the next session (cost real time)

1. **Manifest alignment in hybrid links**: with the payload object on
   the link line, macOS dead-strip packs `__TEXT,__const` differently
   and `ap_aot_manifest` landed on an ODD address (0x...f measured) —
   the plain CRT's `&[ManifestRow]` slice cast is a misalignment UB
   abort there. The hybrid CRT reads every u64 via `read_unaligned`
   (word-indexed, same 64-byte stride) and payload blobs carry
   `set_align(8)`. If a future change reintroduces a slice cast over
   manifest rows, re-check alignment on the HYBRID link specifically.

   `CARGO_TARGET_DIR=~/.git/worktrees/leaf-d13/target` (the T121
