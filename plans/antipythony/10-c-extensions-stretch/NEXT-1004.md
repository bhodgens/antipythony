## The two gate-found bugs (cost honesty)

1. **Unprefixed exports**: extensions reference `_PyObject_CallOneArg` —
   the binary must export CPython-SPELLED symbols; `apx_`-prefixed names
   only work for symbols OUR headers alias. Cost ~25 min (trace: silent
   ModuleNotFoundError → AP_IMPORT_TRACE → dlopen failure).
2. **Receiver payload linkage**: tp_new's alloc path attached the payload,
   but tp_init/method/getset receivers were minted as plain Opaque handles
   → `ApxInstancePayload(self)` NULL → SystemError. mint_slf mints
   CeInstance handles keyed like alloc_ce_instance. Cost ~30 min.

## Payload model decision (recorded)

SIDE REGISTRY keyed by the instance object's stable Arc address — handle
slots rejected because handles are per-call mints (payload would evaporate
between calls or force persistent handle threading through every bridge
entry). Tradeoff: blocks need explicit dealloc wiring (tp_dealloc →
payload_take, S1-remain; currently process-exit frees). basicsize flows
spec → walker → register → SpecRecord → alloc_ce_instance.
