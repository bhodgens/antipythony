## What landed

1. **Shared-layer fixes (ap-run ONLY — wasm codegen untouched, per leaf
   ownership).** The triple-diff found TWO native-leg divergences inside
   the wasm corpus families; both fixed, both small:
   - `generators.rs resume_live`: `throw()` on a FINISHED generator
     (exhausted / closed-before-start / retired) re-raises the thrown
     exception AT THE CALL SITE — CPython 3.14 behavior. The old arm
     rewrote non-SI/GE throws into an empty `StopIteration`; CPython
     propagates the original exception (GE003's `q.close();
     q.throw(ValueError('post-close'))` line). The exhausted G8 path
     (absent entry) already re-raised — the two arms now agree.
   - `interp.rs Expr::Named` + `frame.rs is_comp`: walrus inside a
     comprehension binds in the nearest ENCLOSING non-comp scope
     (S-02-2 / CPython NamedExpr rule). The store used the eval frame,
     which inside a comp is the comp pseudo-frame — the name vanished
     with it (GE005's `y := x * 10` line read back as NameError).
     `Frame::new_child` now sets `is_comp: true`; the Named arm walks to
     the first non-comp ancestor for the store (module scope => global
     bind, matching CPython's leak-to-defining-scope semantics).
