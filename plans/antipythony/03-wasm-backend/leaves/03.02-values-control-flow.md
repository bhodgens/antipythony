# Leaf 03.02 — ap-codegen-wasm values + control flow

## Source
plans/antipythony/03-wasm-backend/orchestrator.md §03.02. Representation
contract: docs/spec/07-wasm-repr.md (from 03.01 — do NOT make representation
decisions here; anything unspecified goes back to the orchestrator).
Design draft: docs/03-wasm-representation-design.md §§1-4, 6, 10.
Native reference implementation (semantics source): crates/ap-obj/src
(value.rs, int.rs, ops.rs, str_repr.rs, float_repr.rs, hash.rs, dict.rs)
and crates/ap-run/src (interp.rs control flow). Port discipline: same IR,
same ap-obj semantics, new representation.

## Scope
1. Emit the $pyobj type hierarchy from spec 07 into the wasm type section
   (replace the skeleton's linear-memory-only bootstrap; the hello-world
   test migrates to print via a prelude-built $str).
2. rt_init: singletons (None/True/False/Ellipsis), builtin type objects
   with precomputed MRO + slot tables for the types in this leaf.
3. Values: int (smi i64 fast path + i61-overflow promotion to $bigint;
   struct-based bignum routines in-module per spec-07 §bigint), float
   (binary64), str (ascii/latin1 arrays; repr/str ported from ap-obj
   str_repr.rs), bytes, list/tuple/dict/set construction + core ops.
4. Arithmetic + comparisons: ap-obj ops.rs dispatch order (slot → reflected
   → TypeError text), // % sign rules (S-01-3/4), true-division promotion
   (S-01-6/7), C-13 no wrapped result escapes.
5. Control flow: if/while/for/break/continue (pending-jump lowering as
   ap-run does), LEGB name resolution (S-02-1/2), Assign/AugAssign/Del,
   truthiness (S-01-27).
6. Function calls + closures: uniform calling convention (spec-07 §CC),
   $code/$function/$cell emission, defaults at def time (S-02-7),
   param binding errors with CPython text (S-02-8..10).
7. Harness flag: `ap-conform run --impl 'ap-host run'` (the tests/t16_hybrid
   suite already cites this shape — keep it exact).
