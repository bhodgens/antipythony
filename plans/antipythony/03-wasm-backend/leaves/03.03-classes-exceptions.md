## Scope
1. Type objects as $type wasm structs: name, precomputed MRO array (C3 at
   build time, not runtime), slot-id method table filled eagerly along the
   MRO, bases tuple, class __dict__.
2. Class creation pipeline: bases/metaclass evaluation order (S-03-1/2),
   namespace execution (S-03-3), type() three-arg form, __init_subclass__/
   __set_name__ hooks per spec 03.
3. Attribute access lowering: data descriptors → instance dict → non-data
   descriptors (S-03-9), setattr/delattr (S-03-10/11), property/staticmethod/
   classmethod descriptor structs.
4. Instance calls: type(C).__call__ protocol (S-03-28), __init__/__new__.
5. Wasm EH mapping: `throw $tag_pyexc` with (ref $exception) payload;
   try/except via try_table + catch; bare except (S-02-31); else (S-02-32);
   finally on every path incl. EH paths (S-02-33) via catch_all_ref rethrow;
   raise forms + bare re-raise (S-02-27/28); __context__/__cause__/
   __suppress_context__ chaining (S-02-34).
6. Traceback: frame-context chain built in lowered prologues from
   Stmt::Line markers; $tb_frame structs (filename/funcname/lineno/col/
   end_lineno); source-map data section emitted per module.
7. Host boundary: ap-host renders an escaped (ref $exception) in
   CPython format to stderr ("Traceback (most recent call last):" +
   "File ... line N, in f" + source echo + "TypeError: msg") byte-identical
   to CPython 3.14; exit code 1.
8. Version constraint enforced at load: ap-host rejects modules whose
   aprt_version is incompatible; document wasmtime >= 47 requirement in
   the crate README/docs (EH on by default; >= 37 behind
   `Config::wasm_exceptions(true)`).
