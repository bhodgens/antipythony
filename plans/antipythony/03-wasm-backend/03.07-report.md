## 5. The V016 case (values family): the ONE native-surface non-lowering gap

`values/V016-encode-decode-errors` fails native (46/47): the utf-8 surrogate
encode error is missing. Root-caused THIS SESSION (`V016-root-cause.md`):
ruff_python_parser 0.0.4 maps `\uXXXX` escapes in D800-DFFF to U+FFFD at
PARSE time (`string.rs:179`), so the runtime's correct surrogate rejection
(encode_str, methods.rs:2294) never sees a surrogate. Fix requires a
parser-layer shim or upstream ruff patch — ap-parse is Plan-01 surface,
outside 03.07's file ownership. Pre-existing on trunk (byte-identical
reproduction); red since 02.03, documented at every gate since.
