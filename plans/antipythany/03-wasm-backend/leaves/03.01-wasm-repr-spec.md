## Deliverable

citing either a spec clause (S-01-*, S-02-*, S-03-*), a compat-contract
clause (C-*), or a p2w-documented precedent:
1. $pyobj struct hierarchy: int (smi/big kind tag, i61 contract), float,
   str (ascii/latin1 + ucs2/ucs4 array layout, cached hash), bytes, bool
   (int-typed singletons, S-01-9), none/ellipsis singletons, list/tuple/
   dict/set/frozenset storage (dict = CPython compact layout port,
   S-01-21..24), $instance generic-attrs shape.
2. Type objects: $type struct, precomputed MRO array, slot-id method table
   (enumerate the FULL slot-id list, shared with native dispatch enum).
3. Closures: $code / $function / $cell layout, late-binding cells (S-02-12).
4. Calling convention: uniform (fn, args, kwargs) wasm signature + static
   specialization rule (§3 of the design doc).
5. Bigint: struct-based in-module (design-doc §4 decision — record the
   reasoning: portability, GC rooting, shared-source byte-exactness).
6. Exception object: $exception carrying type/args/traceback/context/cause
   refs; Wasm EH exnref payload rule; wasmtime >= 47 version constraint
   (>= 37 behind flag) recorded as normative.
7. Generator: $generator state struct + state-machine switch lowering.
8. String round-trip: all three CPython internal encodings must survive
   str -> internal -> repr/str byte-exact (orchestrator 03.01 requirement).
9. GC ownership: engine WasmGC owns object lifetime in wasm mode; MMTk
   never runs; __del__ and weakref divergences recorded as Class-X with
   tracked issues (design doc §8).
10. Gap list: anything deferred (weakref refusal, __slots__ layout,
    stack-switching generators) with the revisit trigger named.
