## What this session fixed (each isolated with a minimal probe,
verified side-by-side against python3.14 where applicable)

1. Class-truthiness metaclass protocol (scrapy Scheduler._mq blocker):
   `assert <class-object>` dispatched the class's OWN `__len__` unbound.
   Class-as-instance dunder lookups (__bool__/__len__/__iter__ etc.) on
   USER classes are now metaclass-only in BOTH special_lookup (classes.rs
   UserClass arm) and attr_get (interp.rs Type|UserClass arm). Interned
   builtin Types keep their MRO surface. Metaclass __len__ DOES apply.
2. `dict.__init__(self)` chain (vendored collections.OrderedDict ctor):
   attr_get Type+__init__ arm returns `__ap_base_<t>__init__` BuiltinFn
   markers for list/tuple/dict/set/frozenset; call_method gained call
   arms for Dict/List/Tuple/Str/Set `__len__` and Dict
   `__getitem__`/`__contains__`/`get` (the attr arm binds BoundMethod
   markers that previously had no call path).
3. Dict-derived len(): OrderedDict instances size via their `__ap_dict__`
   backing (user_len + builtin_len).
4. struct_time unpack: struct_time/uname_result/stat_result/statvfs_result
   are sequences over their `<values>` list (special_lookup Opaque arm +
   iterable_of). `datetime.fromtimestamp` byte-matches CPython.
5. Closure cell chain (root fix, Wave-60 deferred-free resolution): a
   SELF-RECURSIVE def's binding lives in the def's PARENT scope, but
   resolution stopped at the def itself. Now climbs the scope-path prefix
   chain (skipping bare `<locals>` tails) to the first scope that truly
   binds the load, AND propagates the free through intermediate scopes
   (CPython transitive co_freevars). functools.register/singledispatch
   decorator chains work. Probe files: /tmp/w111_crawl/probe_cell*.py.
6. Function `__annotations__`: a blanket empty-dict arm for Function kind
   shadowed the parked source strings; attrs now win. functools
   register(func) falls back to `__annotations__` when the PEP-749
   `__annotate__` cell is absent (vendored functools.py patch).
7. `eval(src, globals[, locals])`: honors the namespace args (module
   frame over the GIVEN globals; locals entries merged). ForwardRef.
   evaluate works.
8. cached_property isinstance (attrs slots rebuild blocker): the
   name-only arm `isinstance(<any function>, cached_property) == True`
   made attrs read `.func` off RAW functions. Now requires the
   `__ap_cached_property__` marker attribute (builtins.rs
   type_matches).
9. `int()` protocol fallthrough: a UserInstance WITHOUT `__ap_int__`
   falls through to user `__int__`/`__index__` (builtins.rs
   builtin_int). Vendored ipaddress IPv4Address/IPv4Network work.
10. IntEnum ordering: member comparison unpack also reads `_value_`
    (enum members with a custom `__new__`, e.g. inspect._ParameterKind).
    `'<' not supported between instances of '_ParameterKind'` gone.
11. IntEnum hash/eq via payload: int-derived instances carry the numeric
    value in `__ap_int__`; py_hash hashes it; values_eq crosses
    Int<->payload-instance (crates/ap-obj/hash.rs + dict.rs int_payload;
    classes.rs parks the payload). `http.client.responses[200]` works.

## Scrapy crawl state (probe6.py = /tmp/w111_crawl/probe6.py)

Latest run: engine opens the spider ("Spider opened"), all middleware/
extensions/pipelines build, logstats runs ("Crawled 0 pages"), then:

    RuntimeError: Task got bad yield: <Deferred at ...>

Root shape: scrapy's CrawlerRunner._crawl is @inlineCallbacks; its
generator YIELDS Deferreds. Our vendored asyncio Task.__step treats any
non-Future/non-None yield as bad (tasks.py ~line 373 "Task got bad
yield"). CPython never drives inlineCallbacks generators with asyncio
Tasks — twisted drives them itself. Two candidate fixes:

a) The Twisted/asyncio bridge: scrapy's is_asyncio_available() needs an
   installed AsyncioSelectorReactor; deferred_from_coro then uses
   Deferred.fromFuture(asyncio.ensure_future(coro)). The inlineCallbacks
   generator should be driven by twisted's _inlineCallbacks machinery,
   not a Task. Check why our engine ends up inside Task.__step for it.
b) Cheaper shim: teach Task.__step to recognize a Deferred yield
   (twisted.internet.defer.Deferred) and bridge via
   Deferred.asFuture(loop) / add_done_callback→__wakeup.

Also open on the same path: `install_reactor` hang (above) — scrapy
itself calls install_reactor during CrawlerProcess init, so the hang
may be the SAME root cause as the bad-yield (the reactor never installs,
scrapy falls back to a non-asyncio path that then drives generators
differently). Fix the hang first; the bad-yield may disappear with it.
